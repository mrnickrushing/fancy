# Oh! You Fancy Focaccia

Website for **Oh! You Fancy Focaccia** — a small-batch organic focaccia bakery in
Brookings, Oregon, run by Amanda. She sells at the Brookings-Harbor Farmers Market
and ships and delivers.

## Status

Pre-build. Research only so far.

## Repo layout

| Path | What's in it |
|---|---|
| `research/facebook-research.md` | Full business research brief — identity, contact, products, reviews, brand voice, and open questions. Start here. |
| `research/business-data.json` | The same facts in machine-readable form, for wiring into the site and structured data. |
| `research/assets/` | Images recovered from the Facebook page. Reference only — use the client's originals for the real site. |

## Before building

`research/facebook-research.md` ends with a list of things only Amanda can answer —
phone number, prices, market schedule, how to order, shipping. Several of them block
real page content, so get them answered early.
